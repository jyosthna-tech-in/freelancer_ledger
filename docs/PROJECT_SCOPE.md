# Project scope

## MVP

The first MVP is a local demo of a freelancer ledger with these capabilities:

1. Local demo login
2. Clients
3. Invoices
4. Payments
5. Outstanding balances
6. Invoice search

All MVP work runs on a local machine. Data is scoped by `userId`. Money uses integer `amountMinor` values.

## Non-goals (first MVP)

The following are explicitly out of scope for the first MVP:

- Payment processing
- Real AWS deployment
- Real Cognito login
- AI assistant
- OpenSearch semantic/vector search
- Automated email
- Team collaboration
- Mobile app
